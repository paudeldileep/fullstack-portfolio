# Accessibility (WCAG 2.2 AA baseline)

## Must-haves
- Semantic landmarks + skip link
- Keyboard navigation everywhere
- Visible focus styles (focus-visible)
- AA contrast for text and interactive controls
- Reduced motion support
- Form labels + accessible errors
- Decorative SVGs aria-hidden

## Review checklist
- Tab order correct
- No keyboard traps
- Headings hierarchical (H1 once, H2 per section)
- Links/buttons have accessible names
