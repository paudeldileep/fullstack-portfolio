# Section Layout Specs (Home: long-scroll)

## General rules
- Each section has a unique `id` (anchor navigation)
- Render ONLY if block exists and has data
- Each section has H2 + optional intro text

Order:
1. Hero
2. About
3. Skills
4. Experience Timeline (curvy alternating)
5. Projects
6. Testimonials (optional)
7. Certifications (optional)
8. Education (optional)
9. Social Links (optional)
10. Contact

## Experience timeline
- Alternating left/right cards on desktop
- Decorative SVG “road” aria-hidden
- Mobile collapses to single-column list
