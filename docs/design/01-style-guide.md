# Style Guide

## Design goals
- Clean, modern, minimal “engineering portfolio”
- Strong readability, generous spacing, subtle motion
- WCAG 2.2 AA compliance
- Consistent across light/dark themes

## Layout system
- Max content width: 1120px (desktop)
- Horizontal padding: 16px mobile, 24px tablet, 32px desktop
- Section vertical padding: 64px mobile, 96px desktop
- Grid: 1 col mobile, 2 col tablet, 12 col desktop (as needed)

## Spacing scale (8px base)
4, 8, 16, 24, 32, 48, 64, 96

## Typography
- Sans: Inter (recommended) or system stack
- H1 44–56, H2 32–40, H3 22–28, Body 16–18

## Components
- Buttons: 44x44 min hit target, focus-visible ring
- Cards: radius 16–20px, subtle border/shadow
- Links: underline on hover (or always underline in body text)
- Forms: visible label, helper/error text

## Motion
- 150–250ms transitions
- respect prefers-reduced-motion
