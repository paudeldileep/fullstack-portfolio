# Color Tokens (Draft)

We will start with a Neutral + Blue palette and make tokens editable via Admin later.

## Required tokens (CSS variables)
- --bg, --surface, --surface-2
- --border
- --fg, --muted
- --primary, --on-primary
- --accent
- --focus
- --shadow

## Rules
- Maintain AA contrast for:
  - body text vs background
  - interactive controls vs background
  - focus indicator visibility
- Do not use color alone to convey meaning.
