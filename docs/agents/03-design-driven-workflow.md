# Design-driven workflow (for agents)

## Process
1) Pick ONE section/capability for the PR.
2) Save design references to `docs/design/inputs/<section>/` with a short README.
3) Implement using shared tokens/components.
4) Screenshot (light/dark, desktop/mobile, focus).
5) Compare to reference and iterate.
6) Run checks and include evidence in PR.

## Acceptance criteria
- Matches design hierarchy and spacing
- Responsive works
- A11y basics pass
- Section renders only when data exists
