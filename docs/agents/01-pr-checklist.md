# PR Checklist

## Build & Quality
- [ ] pnpm lint
- [ ] pnpm typecheck
- [ ] pnpm test (or N/A)
- [ ] pnpm build

## Accessibility
- [ ] Keyboard navigation works
- [ ] Visible focus styles present
- [ ] No obvious contrast issues
- [ ] Images have alt text (or are decorative)

## SEO (if applicable)
- [ ] Metadata present
- [ ] Canonical correct

## Security (if admin/API touched)
- [ ] Auth middleware applied
- [ ] Input validation
- [ ] No secrets committed

## Evidence
- [ ] Light + dark screenshots for UI changes
- [ ] Focus-visible screenshot if interactive
