# Screenshot & Visual QA

## When required
If you change UI layout/typography/colors/spacing/components: take screenshots.

## What to capture
- Home sections (that exist in seed data): hero, about, skills, experience, projects, testimonials, certifications, education, social links, contact
- Blog list + blog post
- Project detail
- Admin: login + dashboard (when available)

## Naming
Store in `docs/design/screenshots/<date-or-pr>/`:
- home-<section>-desktop-light.png
- home-<section>-desktop-dark.png
- home-<section>-mobile-light.png
- home-<section>-mobile-dark.png
- home-<section>-focus.png

## Compare
Compare with reference designs in `docs/design/inputs/<section>/`.
If mismatch: iterate until aligned or explain updates.
