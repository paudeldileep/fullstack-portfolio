# Agent Rules (Must Follow)

## Goal
Make small, reviewable changes as a professional engineer.

## Non-negotiables
- One task per PR.
- No unrelated refactors.
- Keep WCAG 2.2 AA intent.
- No hardcoded content for public pages; fetch from API/DB unless task says otherwise.
- Provide evidence (tests + screenshots when UI changes).

## Design Inputs (critical)
- The user may provide design references per section (images/SVGs/Figma exports).
- Treat the latest design input as the source of truth for that section.
- If design conflicts with older specs, prefer the newer design and note it in PR.

## PR description format
- Summary:
- Files changed:
- Commands run:
- Screenshots:
- Checklist:
- Risks / Follow-ups:
